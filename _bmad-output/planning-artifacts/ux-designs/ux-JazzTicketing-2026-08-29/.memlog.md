- (decision) Design posture: back-of-house utility instrument, not consumer polish. Optimised for one hand, gloves, dim corridors, motion, and interruption — legibility and target size beat density and elegance.
- (decision) SLA state is encoded by text + glyph + position, never colour alone (PRD NFR-6). The time remaining is always readable as a number; colour is redundant reinforcement.
- (decision) Offline is a first-class visible state, not an error: queued actions show a per-item marker and a persistent count, and no action is ever blocked for being offline (PRD FR-58).
- (decision) Bidirectionality is structural: every layout is authored logical-direction-first (start/end, never left/right) because Hebrew and Arabic ship in the locale set (PRD FR-61).
- (decision) Shared-device sign-in is a designed screen, not a login form: PIN pad with language selection on the same surface, because the sign-in screen must be usable before a language is known (PRD FR-4, FR-61).
- (assumption) Role determines the home surface: Room Attendant lands on Board, Engineer and Runner land on My Work, Supervisor lands on Floor. Single app, role-shaped entry.
